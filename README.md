# صيدليتي | Pharmacy POS

نظام إدارة صيدلية يعمل من خلال صفحة HTML واحدة، ويشمل المبيعات والمخزون والمشتريات والموردين وحساباتهم والمرتجعات والمصروفات والعملاء والورديات والتقارير والمستخدمين والصلاحيات.

## التشغيل

افتح الملف:

`pharma store.html`

بيانات المدير الافتراضية:

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

سيطلب النظام كود تفعيل صحيحًا صادرًا من صفحة `كود التفعيل.html`.

## المزايا

- إدارة الأصناف والأدوية والباركود والمخزون.
- البيع بالعلبة أو الشريط أو القرص.
- تسجيل المشتريات برقم فاتورة المورد.
- اختيار المورد من قائمة الموردين المسجلين.
- حسابات الموردين والمدفوع والمتبقي.
- المرتجعات والمصروفات والعملاء الآجل.
- الجرد والورديات والتقارير.
- صلاحيات منفصلة لكل مستخدم.
- تعديل كلمة السر.
- فصل العمليات الأساسية عن العمليات الحساسة مثل PDF وExcel والطباعة والتقفيل.

## Google Sheets

1. أنشئ Google Sheet جديدًا.
2. افتح `Extensions > Apps Script`.
3. الصق محتوى `google-sheets-sync.gs`.
4. اختر `Deploy > New deployment`.
5. اختر النوع `Web app`.
6. اجعل التنفيذ `Me` والصلاحية `Anyone`.
7. انسخ رابط Web app.
8. افتح إعدادات البرنامج والصق الرابط ثم اضغط حفظ وربط.

سيتم إرسال الأصناف والمبيعات والمشتريات والموردين والحسابات والمرتجعات والمصروفات والعملاء والورديات وسجل الحركة إلى تبويبات منفصلة.

## ملاحظات أمنية

- غيّر كلمة مرور المدير قبل الاستخدام الفعلي.
- لا ترفع بيانات العملاء أو كلمات المرور الحقيقية إلى مستودع عام.
- احتفظ برابط Google Apps Script داخل إعدادات خاصة إذا كان المستودع عامًا.
